# Fatores de sucesso


* **Saber desde o começo como falar com o consultor territorial.** As equipes precisam conhecer o canal e os horários de contato.  
* **Manter os encontros de gestão com agenda definida.** A agenda e a frequência combinadas no plano de trabalho ajudam todos a se organizar e a participar.  
* **Usar os dados do Painel de Gestão como base dos encontros.** Os indicadores dão um ponto de partida concreto para a conversa.  
* **Espalhar o que funciona.** Quando uma UBS encontra um jeito melhor de usar uma solução, o consultor pode levar a ideia para as outras unidades.

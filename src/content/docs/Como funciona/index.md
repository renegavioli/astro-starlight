# Como funciona


O CARDIO funciona em três grandes esferas:

1) Uma abordagem, que define as bases do trabalho e dá o acrônimo do nome do projeto.  
2) Um pacote de soluções, que é o que chega às UBS.  
3) Uma jornada de implementação, que é o caminho que o município percorre com a equipe CARDIO.

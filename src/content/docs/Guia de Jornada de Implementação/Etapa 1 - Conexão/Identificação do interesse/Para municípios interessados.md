# Para municípios interessados


O CARDIO está hoje em 46 municípios brasileiros. Um município que tenha interesse no CARDIO pode procurar a equipe pelo \[canal de contato a definir\].

A entrada de um novo município depende da existência de recursos dos investidores parceiros para aquele território.

Para conhecer o CARDIO antes de uma conversa, veja as páginas **O que é o CARDIO**, **Como funciona** e **Resultados**.

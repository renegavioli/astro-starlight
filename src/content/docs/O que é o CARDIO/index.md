# O que é o CARDIO


O CARDIO é uma iniciativa que fortalece a Atenção Primária à Saúde (APS) para prevenir e cuidar das condições crônicas não transmissíveis (CCNT), como hipertensão, diabetes, obesidade e colesterol alto. 

***O objetivo é transformar a saúde cardiovascular da população, município a município, paciente a paciente.***

# Linha de Cuidado

É uma estrutura orientadora que organiza e padroniza as ações voltadas à trajetória do paciente no sistema de saúde. Abrange ações de promoção, prevenção, tratamento e reabilitação.

Seu objetivo central é orientar os serviços para que o cuidado seja centrado nas necessidades do paciente, tendo a **Atenção Primária como coordenadora dos fluxos assistenciais**.

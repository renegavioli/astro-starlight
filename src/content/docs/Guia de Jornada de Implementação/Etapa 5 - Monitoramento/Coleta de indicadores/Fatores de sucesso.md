# Fatores de sucesso


* **Registrar tudo num único sistema oficial.** Os dados do cuidado com as CCNT devem ser lançados no sistema de informação oficial do município, como o e-SUS. Isso evita retrabalho e informações desencontradas.  
* **Preencher o Painel todo mês, sempre na mesma época.** Dados em dia permitem acompanhar a evolução e agir rápido.  
* **Usar os dados como ponto de partida das reuniões.** Os indicadores do Painel dão um tema concreto para a conversa nos encontros de gestão e nas reuniões técnicas das UBS.  
* **Devolver os dados para quem está na ponta.** As equipes das UBS se engajam mais quando sabem como a unidade está indo. O Mural de Prevalência ajuda nisso.  
* **Não criar registros extras para a ponta.** Antes de pedir um novo registro, vale ver se a informação já pode sair dos sistemas que o município usa.

# Responsabilidades


#### **Equipe CARDIO**

* Preparar os documentos da parceria e acompanhar as assinaturas.  
* Deixar o ACT e os aditivos acessíveis para o município.  
* Definir internamente o consultor de implementação e as tarefas de cada área da equipe CARDIO antes do kick-off.  
* Conduzir o kick-off: retomar o projeto, apresentar as soluções e combinar os próximos passos.  
* Explicar quais informações o município precisa reunir para o diagnóstico situacional.

#### **Município**

* Encaminhar os documentos para assinatura dentro da prefeitura.  
* Definir as pessoas que vão conduzir o CARDIO no município.  
* Participar do kick-off com essas pessoas.  
* Começar a reunir as informações solicitadas para o diagnóstico situacional.

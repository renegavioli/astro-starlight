# Como acontece


A equipe CARDIO apresenta:

* o que é o CARDIO;  
* os resultados já alcançados;  
* o que o CARDIO entrega ao município;  
* como funciona a parceria e quanto tempo ela dura.

Depois das apresentações, a SMS decide se quer participar. Se sim, ela dá o seu de acordo e a jornada segue para a Adoção, quando a parceria é formalizada.

**Pontos para você checar**

1. **Descrevi os artigos em uma linha, a partir do título de cada um.** Não li os cinco por inteiro. Antes de publicar, vale conferir as descrições, principalmente a de Jarrett et al., que o *Onboarding* cita no slide sobre Design Thinking. Também conferi só pelas citações qual artigo trata de quê.  
2. **A lista tem cinco artigos, mas a *Narrativa* fala em nove.** Os outros devem estar entre os PDFs do projeto, cujos nomes de arquivo não dizem o título. Se quiser, levanto a lista completa a partir desses arquivos.  
3. **O papel do município continua indefinido.** Não sei se o município autoriza o uso dos dados, se é coautor ou se só é informado. Escrevi “acompanham o processo”. É a mesma pergunta da página da Escala.  
4. **O primeiro fator de sucesso repete um da avaliação de resultados.** Se a revisora achar redundante, esta página pode ficar só com o fator dos parceiros acadêmicos.  
5. **A página fala mais com a equipe CARDIO do que com o município.** Talvez caiba uma frase sobre o que o município ganha com um artigo, como visibilidade e argumentos para manter o CARDIO. Isso seria inferência minha, então não incluí.

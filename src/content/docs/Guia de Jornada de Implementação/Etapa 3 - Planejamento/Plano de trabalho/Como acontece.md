# Como acontece


O plano de trabalho é um documento único. Ele não precisa ficar pronto de uma vez. As decisões acontecem aos poucos, e cada uma entra no plano assim que é tomada. Isso evita que as informações do município fiquem espalhadas em vários documentos.

O plano de trabalho reúne:

* **Soluções:** quais soluções serão implementadas e quais adaptações foram acordadas no workshop de cocriação.  
* **UBS participantes:** quais UBS recebem o CARDIO e, se houver mais de uma onda, quais entram em cada uma delas.  
* **Cronograma:** quando cada atividade da jornada vai acontecer.  
* **Indicadores:** quais indicadores serão acompanhados no Monitoramento.  
* **Governança:** quem são as pessoas responsáveis no município e na equipe CARDIO, quais são os papéis de cada uma e com que frequência acontecem os encontros de gestão.

Enquanto o plano é montado, acontecem as reuniões técnicas com outras áreas da prefeitura, como jurídico, tecnologia da informação e comunicação. Nelas, a equipe CARDIO entende os processos de cada área e combina o que é preciso para avançar.

Quando estiver pronto, o plano de trabalho é apresentado à gestão de saúde do município, junto com o diagnóstico situacional.

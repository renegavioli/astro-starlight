# Planejamento


*Etapa 3 de 7 · Anterior: Adoção · Próxima: Implementação*

No Planejamento, a equipe CARDIO e o município conhecem a realidade das UBS e decidem juntos como o projeto vai funcionar ali. É também quando os materiais começam a ser preparados.

Esta etapa leva pelo menos dois meses a partir do kick-off.
